# Igreja de Deus Fortalecendo Famílias

## Como testar o site

1. Certifique-se de ter o repositório clonado em sua máquina local.
2. Abra o arquivo `index.html` diretamente em seu navegador favorito ou use uma extensão como **Live Server** (VS Code) para servir a página.
3. Caso utilize um servidor local, execute-o apontando para a raiz do projeto e acesse `http://localhost:PORTA/index.html`.
4. Navegue pelas seções (Início, Quem Somos, Ministérios, Palavra Viva, Eventos e Contato) verificando a responsividade em diferentes tamanhos de tela.
5. Interaja com os botões e animações para garantir que todos os efeitos visuais estejam funcionando conforme esperado.
6. Valide se as fontes, cores e logotipo são carregados corretamente e se não há erros no console do navegador.

Seguindo esses passos você confirma que o site está renderizando como planejado.
